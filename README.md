# KazeSU-Docs

The KazeSU documentation website.

[![Pages](https://github.com/KazeSU/KazeSU.github.io/actions/workflows/main.yml/badge.svg)](https://github.com/KazeSU/KazeSU.github.io/actions/workflows/main.yml)

## Development

### Requirement

- NodeJS 22+

### Commands

```shell
npm install

# dev
npm run docs:dev -- --host

# build
npm run docs:build

# preview
npm run docs:preview
```

## Notes

This website uses `MiSans VF` and `JetBrains Mono` fonts, and is built with
[VitePress](https://vitepress.dev).
